# 自生长与接手

“自生长”是持续积累和可解释的偏好维护，不是模型自动训练，也不是无限扩大爬取范围。

每次结束在 `reports/` 新建带时间的 Markdown 报告：本轮范围、尝试来源、实际新增/复用数量、未入选原因、失败与待补条目、本地校验结果、各目标的状态和范围、界面检查范围。无新增就写无新增；运行报告不含 cookie、token、授权地址查询参数或完整接口响应。

用户收藏、排除或纠正时，将明确偏好记入 `preferences.md`，标注来源和日期。重复出现的新标签先与已有词表合并；有依据的相关条目可以互加链接，不能臆造关联。新增网站写 `sources-candidates.md`，附推荐理由，等用户选定后启用。规则与主题的重要变更先呈现建议。

每次报告说明剩余工作，HANDOFF 链接最近报告。新 Agent 接手：
1. 读取配置、索引、偏好和最近报告。
2. 验证路径、时区、当前连接账号与所选目标。
3. 运行本地 verify；对 unknown 先查远端；按条目补 pending/failed。
4. 恢复已有编号和关联，不能从零再跑整个库。

手动同步笔记内容或标签后，相关外部目标需重新核对并更新状态。脚本自动察觉新增附件，但不会监控用户在其他软件里的编辑，也不提供双向删除同步。首版是本地向目标的增量同步工作流。
