# 自生长素材知识库 · material-collector

一个通过提问帮助用户选择素材来源、筛选条件和保存位置的 Agent Skill。提供本地素材入库工具，可选 Obsidian、Eagle 和用户自己的飞书。

**这是供 Agent 执行的技能，不是独立爬虫或后台服务。** 网页采集和外部同步使用运行它的 Agent 已有工具。没有相应工具时，会留下明确的待办状态。

## 开始使用

将整个 `material-collector` 文件夹放入 Agent 支持的技能目录，或直接让 Agent 读取该文件夹的 `SKILL.md`。具体安装位置遵循宿主产品的当前说明。

可以这样说：

> 使用 material-collector，帮我建立自己的素材知识库。先问我收集主题、网站、保存位置，以及是否同步飞书。先试采 3 条。

也可以说：

> 继续维护我指定目录下的素材库，先读配置和最近报告，只补失败项并收集本轮新增。

首次设置包括：主题与来源、筛选范围、保存目标、可选飞书、手动或定期。默认不启用任何网站、不上传飞书、不建立定时任务。源站登录和受限内容遵循实际权限。

## 得到什么

- 原始来源、摘要、附件和标签构成的素材条目。
- 普通 Markdown 知识库与可追溯附件索引。
- 增量去重、失败补录、逐目标同步记录。
- 用户偏好与新 Agent 接手资料。

所有模式都有本地状态目录。Obsidian 可直接读取 Markdown；Eagle/飞书需要宿主的连接能力。同步为单向增量工作流，不提供跨端删除传播。

## 本地工具验证

Python 3.10+，仅标准库：

```bash
python3 scripts/selftest.py
python3 scripts/library.py --help
```

输入模板见 assets，操作说明见 references/operations.md。真实配置和素材应放到技能目录以外。

## 验证范围

本地初始化、来源/内容去重、增补、笔记保留、同步证据约束和附件损坏检测有自动测试。外部采集、Obsidian 界面、Eagle 与飞书真实账号集成须在使用者环境里试采验收；未承诺所有 Agent 通用直连。
